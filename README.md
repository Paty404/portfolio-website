# Portfólio Pessoal

Projeto desenvolvido como trabalho final da disciplina **Desenvolvimento front-end para Web**, com o objetivo de aplicar os conhecimentos adquiridos ao longo do semestre em desenvolvimento web.


## Sobre o Projeto

Este projeto consiste em um site de portfólio pessoal construído utilizando as tecnologias fundamentais da web: HTML, CSS e JavaScript. O site foi criado para apresentar informações pessoais, acadêmicas e formas de contato, servindo também como prática integrada dos conceitos estudados na disciplina.


## Objetivos

• Aplicar na prática os conceitos de HTML semântico, estilização com CSS e interatividade com JavaScript;
• Consolidar os aprendizados adquiridos ao longo do semestre;
• Desenvolver um projeto completo e funcional do zero.


## Tecnologias Utilizadas

• **HTML5** — estrutura e semântica do conteúdo;
• **CSS3** — estilização, layout e responsividade;
• **JavaScript** — interatividade e dinamismo da página.


## Funcionalidades

• Página inicial com apresentação pessoal;
• Linha do tempo da minha jornada Estudantil;
• Área de habilidades e competências;
• Seção de contato;
• Layout responsivo para diferentes dispositivos;
• Links para Redes Sociais como LinkedIn e Github.
